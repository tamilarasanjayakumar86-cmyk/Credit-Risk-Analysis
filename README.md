# Credit Risk Analysis

## Project Overview
Credit Risk Analysis is a Data Science project that analyzes previous loan application data using Python, SQL, Exploratory Data Analysis (EDA), and Streamlit.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Plotly
- MySQL
- SQL
- Streamlit

## Project Workflow
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Data Visualization
5. MySQL Database Integration
6. SQL Query Analysis
7. Streamlit Dashboard Development

## Features
- Loan application analysis
- Application status analysis
- Customer type analysis
- Credit amount analysis
- Interactive dashboard
- MySQL database integration

## Dataset
The project uses previous loan application records containing customer, loan amount, contract type, payment type, and application status information.

**Note:** Previous application status is not the same as actual loan repayment status.

## How to Run

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the Streamlit dashboard:

```bash
streamlit run app.py
```
